# Uptimecheck Provider

Manage Uptimecheck monitors as code, and look up alert channels, projects and status pages.

[Uptimecheck](https://uptimecheck.com) checks websites, APIs, ports, DNS, domains, cron jobs and servers, alerts
the channels you choose and shows the results on public status pages. This provider talks to its REST API
(`/api/v1`, reference at https://app.uptimecheck.com/docs/api).

## Authentication

Create a read & write API key under Settings › API in the app and pass it as `api_key`, or better, set the
`UPTIMECHECK_API_KEY` environment variable so the key stays out of your configuration.

## Example Usage

```terraform
terraform {
  required_providers {
    uptimecheck = {
      source = "uptimecheck-com/uptimecheck"
    }
  }
}

# The API key comes from UPTIMECHECK_API_KEY (Settings › API in the app, read & write).
provider "uptimecheck" {}
```
